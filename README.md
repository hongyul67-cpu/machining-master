## 고칠 곳

`index.html` 위쪽의 `LEARN`(개념 카드)과 `QUESTIONS`(문항) 두 배열만 고치면 됩니다.
게임 문제는 `makeCalc()` · `IDENT` · `WH_ABR`/`WH_BOND` · `PAIRS` 에서 나옵니다.
`makeCalc()` 는 값을 매번 새로 뽑아 문제를 만들므로 문항을 따로 적어 둘 필요가 없습니다.
